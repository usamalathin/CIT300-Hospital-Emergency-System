## Project Description

This project is a Mini Hospital Emergency Management System developed using Java.

The system demonstrates the practical use of Data Structures and Algorithms through:

- Binary Search Tree (BST)
- Queue
- Stack
- Singly Linked List

---

## Features

### Binary Search Tree

- Insert Patient
- Search Patient
- Delete Patient
- Display Patients

### Queue

- Enqueue Patient
- Dequeue Patient
- Display Queue

### Stack

- Push Treatment Record
- Pop Treatment Record
- Display Stack

### Singly Linked List

- Add Visit
- Search Visit
- Remove Visit
- Display Visit History
